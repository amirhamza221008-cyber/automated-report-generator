# 📊 Automated Business Report Generator

An AI-powered business report generator that analyzes CSV data, creates visualizations, and generates professional PDF reports automatically.

## 🚀 Features
- 📁 CSV file upload via web interface
- 📈 Automatic chart generation using Matplotlib
- 🤖 AI-powered executive summary generation
- 📄 Professional PDF report generation
- 🌐 User-friendly Streamlit web interface

## 🛠️ Tech Stack
- **Python** - Core programming language
- **Pandas** - Data analysis and manipulation
- **Matplotlib** - Data visualization and charts
- **FPDF2** - PDF generation
- **Streamlit** - Web interface
- **Google Gemini AI** - AI summary generation
